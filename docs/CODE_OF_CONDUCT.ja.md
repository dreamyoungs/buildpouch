# 行動規範

[プロジェクトREADME](../README.md) | [English](CODE_OF_CONDUCT.md) | [한국어](CODE_OF_CONDUCT.ko.md) | [日本語](CODE_OF_CONDUCT.ja.md)

## 私たちの約束

BuildPouchは、背景や経験レベルにかかわらず、敬意に基づく参加を歓迎します。Contributor、maintainer、communityメンバーには、プロジェクト空間を安全で建設的に保ち、ソフトウェアの改善に集中する責任があります。

## 期待される行動

- 忍耐、誠実さ、敬意をもってコミュニケーションします。
- 異なる視点を歓迎し、実行可能な技術的feedbackを提供します。
- 間違いに責任を持ち、その影響を修復するために協力します。
- プライバシー、相手の境界、セキュリティ報告の機密性を尊重します。
- 議論をプロジェクトとcommunityに関係する内容に保ちます。

## 許容されない行動

嫌がらせ、差別、脅迫、性的な言動、個人攻撃、意図的な威圧、継続的な妨害、なりすまし、許可なく他人の個人情報を公開する行為は認められません。善意で懸念を報告した人への報復も禁止します。

## 適用範囲と執行

このポリシーは、repository、issue、Pull Request、review、discussion、およびBuildPouchを代表するその他の場に適用されます。Maintainerはcommunityを守るために必要な場合、内容の編集・削除、contributionの終了、参加制限、参加者の禁止を行うことができます。執行判断では、深刻度、反復性、文脈、影響を受けた人の安全を考慮します。

行動に関する懸念は、件名に`[BuildPouch conduct]`を付けて[dev-team@dreamyoungs.com](mailto:dev-team@dreamyoungs.com)へ非公開で報告してください。機密情報を公開issueに投稿しないでください。報告は可能な限り機密として扱い、報復なしに確認します。

このポリシーは、[Contributor Covenant 3.0](https://www.contributor-covenant.org/ja/version/3/0/code_of_conduct/)を含む、広く利用されているオープンソースcommunity標準を参考にしています。
